# Verification de la livraison active

Cette livraison active cible les deux premiers cours : premiers pas avec Spring Boot, puis HTTP et JSON. Le socle attendu en salle est **Java 25**, Maven 3.9 et Spring Boot 3.5.16.

Les supports des cours 3 a 8 seront repris plus tard. Les fichiers deja presents pour ces themes ne sont pas encore a considerer comme des supports diffuses.

## Points controles dans cette reprise

- Les consignes d'installation et les deux premiers ateliers mentionnent Java 25.
- Les POM des ateliers utilisent `java.version` 25.
- Les cours 1 et 2 disposent d'un TP guide, d'un quiz corrige et de diagrammes exportables en HTML.
- Le generateur HTML fournit un mode diaporama avec navigation clavier.

Les tests Maven n'ont pas ete relances pendant cette reprise.
