# Exemples complémentaires pour l’enseignant

Ces deux applications regroupent davantage de mécanismes et ne constituent pas les TP du parcours débutant. Pour enseigner les bases, utiliser les huit projets progressifs du dossier [ateliers](../ateliers/README.md).

- [API utilisateurs complète](rest-users/README.md) : exemple d’assemblage après les premières séances, avec validation et filtre de clé.
- [Événements de commande](jms-orders/README.md) : exemple complémentaire de contrat de message structuré.

La lecture de ces projets n’est nécessaire pour aucun quiz ni pour le mini-projet débutant.
